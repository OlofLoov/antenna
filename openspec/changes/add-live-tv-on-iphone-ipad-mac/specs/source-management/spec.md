# Spec Delta

## REMOVED Requirements

### Requirement: Loading until the first channel
**Reason**: Live on iPhone, iPad and Mac lists each source while it loads and, when no source loaded channels, shows a message with Retry instead of leaving "Loading channels…" on screen.
**Migration**: See `live-tv-on-iphone-ipad-mac`, requirement "Sources that fail, are empty or wait for a login", scenarios "Loading, offline, empty or waiting" and "Nothing loaded".
