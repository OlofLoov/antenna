# App Store Connect trader contact

App Store Connect asks every developer whose apps are on sale in the EU
whether they are a trader under the EU Digital Services Act. A trader's
address, phone number and email show on the app's product page in the EU
storefronts. Apple checks them before the app can go on sale there.

## Decided

- **Trader status: yes.** Antuna is sold, so Code Crave, the developer team
  that publishes it, is a trader.
- **Nothing on antuna.app.** The domain receives no email (it has no MX
  record), so the trader email cannot be an address on it. The contact
  details live in App Store Connect only; the site does not show them.
- **Support stays on the site.** The App Store support address is
  antuna.app/support, which gives antuna@code-crave.se. That is separate
  from the trader contact, which Apple shows next to it.

## Still open: the owner supplies these

The owner enters them in App Store Connect when declaring the trader status.
They are not written here.

- **Address:** the postal address Code Crave is registered at.
- **Phone number:** a number Apple can verify and buyers can call.
- **Email:** any domain but antuna.app. antuna@code-crave.se, the support
  mailbox, would work and keeps one inbox for buyers.
